# Gaurav Kumar — Professional Portfolio

Professional responsive portfolio with JavaScript interactions, personal branding, profile photo and GK logo.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — theme toggle, menu, validation, gallery, dynamic greeting
- `images/gaurav-profile.png` — profile photo
- `images/gk-logo.svg` — personal GK logo

## Important
Contact details are configured in `index.html`.

## Run
Open `index.html` in a browser. No installation is required.
