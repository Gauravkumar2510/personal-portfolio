# Gaurav Kumar - Personal Portfolio

A responsive personal portfolio website created for **Developers Arena – Week 1 Task 1: HTML - Your First Website**.

## Project Overview

This project is a simple personal portfolio built with HTML5. It presents my introduction, education, skills, projects and contact information in a clean responsive layout.

## Objectives

- Create a proper HTML5 document structure.
- Use semantic HTML5 elements.
- Add About, Skills, Projects and Contact sections.
- Add navigation between sections.
- Use an image from the `images/` folder.
- Add a contact form with HTML form controls.
- Make the page responsive for mobile and desktop screens.
- Publish the project through GitHub.

## Technologies Used

- HTML5
- CSS3
- Basic HTML form elements
- Responsive CSS media queries

## Folder Structure

```text
personal-portfolio/
├── index.html
├── README.md
└── images/
    └── profile-placeholder.svg
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Use the navigation menu to move between sections.

No server or external dependency is required.

## Main Sections

### Home
Introduction, name, role and call-to-action buttons.

### About
Educational background and short professional introduction.

### Skills
HTML5, CSS3, JavaScript, Python, React Native, Expo and Firebase.

### Projects
Academic and learning projects, including the Smart Waste Management System.

### Contact
Location, GitHub/LinkedIn links and a contact form.

## Technical Requirements Covered

- `<!DOCTYPE html>` and HTML5 structure
- `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Minimum required sections: About, Skills and Contact
- Internal navigation using anchor links
- Image with descriptive `alt` text
- Lists using `<ul>` and `<li>`
- Contact form using labels, inputs, textarea and button
- Responsive layout using CSS media queries
- Separate `images/` folder
- Documentation explaining setup, structure and technical requirements
